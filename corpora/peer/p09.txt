Quicksort [Geed] is a very efficient and widely used recursive sorting algorithm. I used it to sort the tables in Figures 6 and 5. Since this algorithm should either sort an ArrayList [Oraa] of User or an ArrayList [Oraa] of Game objects I implemented it using Java generics [Geeb], which is a technique used for defining a class parameterized on types and therefore eliminates code duplication and makes maintenance easier. Since my version of quicksort should compare objects based on a chosen attribute I implemented a compare method (Figure 26).
