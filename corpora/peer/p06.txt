When the user tries to create a new account in the calendar app it is checked whether the username and email that they are trying to use is already assigned to another account, returning the appropriate message if it is, like is stated in success criterion 4, 6. This is done by performing a search in the database as it can be seen in Figure 17. If the info input aren’t already used, it creates a new user with that info and adds it to the database, completing success criterion 1 (Figure 18).
