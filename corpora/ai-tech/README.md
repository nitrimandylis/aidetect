# How this corpus is generated, and the mistake that shaped it

These 12 paragraphs are the AI half of the technical calibration set. They are
generated by `aidetect generate`, which calls hosted models through NVIDIA NIM
with **no system prompt and no style guidance** — only a topic and a word count.
`manifest.json` records the model, vendor, temperature and exact prompt for each
sample.

## Why the generator exists

The first version of this corpus was written by an AI assistant working inside a
session that carried the repo owner's house writing rules (write tightly, no em
dashes, active voice). That produced an AI class stylometrically **inside** the
human class it was supposed to oppose:

| corpus | mean sentence length | commas per sentence |
|---|---|---|
| contaminated ai-tech (withdrawn) | 25.8 | 1.16 |
| human-tech | 24.5 | 1.12 |
| clean-room ai-tech (current) | 31.5 | 1.94 |

A too-human AI class pulls the clusters together, lowers the fitted threshold and
makes the detector **more lenient** — the false-negative direction, which is the
error this tool exists to prevent. Fitted on the contaminated set, Binoculars
separated only 79% of the samples, and that was wrongly read as "Binoculars is
weak on technical prose". Regenerated clean-room, the same pair separates **92%**,
matching the humanities set. The genre effect is real but it is a shift in level
(human technical prose means 0.828 against humanities' 0.901), not a loss of
discrimination.

## Two things the generator guards

- **Reasoning traces.** One model answered with its planning out loud ("We need to
  write a single paragraph about 110 words...") instead of prose. `looks_like_prose()`
  rejects planning traces, preambles and refusals, and the model is dropped and
  substituted.
- **Length.** Models overshoot the requested word count, and the human samples are
  fixed-size excerpts from long essays. Left alone the AI class ran ~50% longer,
  so the threshold would partly encode "long means machine". Output is trimmed to
  whole sentences at the word budget.

Do not hand-write samples for this folder. Regenerate it.
