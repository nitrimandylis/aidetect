In analysing simplified poker models through the framework of game theory, it is necessary to enumerate the pure strategies available to each player before the game can be represented in strategic form. The first player, possessing multiple information sets, commands a considerably larger strategy space than the second player, whose single information set permits only two possible responses. Once these strategies have been identified, the expected value of each combination can be computed, allowing dominated strategies to be systematically eliminated. This process reduces the payoff matrix to a manageable size and reveals the underlying structure of optimal play.
